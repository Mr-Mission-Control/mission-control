# Mission Control (•ΕΛΕΓΧΟΣ~ΑΠΟΣΤΟΛΗΣ•)

A free, volunteer-built home-screen hub. Install it from this page in Chrome (Install app) to pin it to an Android home screen.

This project is offered at no cost, under the MIT License. It has no trackers, no analytics, and no ads. A launch log, if used, stays on the device.

Live site: https://mr-mission-control.github.io/mission-control/
